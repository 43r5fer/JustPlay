BUILT AROUND YOUR GAME

Small setup. Big possibilities.

JustPlay brings the routine parts of launching Java Edition into one clean desktop experience.

▦

Choose your version

Browse official releases, snapshots and legacy entries. Forge and Fabric are sourced from their official metadata and installers; OptiFine uses its own official download flow.

✣

Mods without the mess

Put JAR mods in a shared folder and copy them into the selected game profile. Use versions and loaders that match each mod.

▧

Resource packs in one place

Manage Java Edition ZIP packs and keep them close to the profile you want to customize.

⌁

Smart storage setup

First-run setup checks writable drives and tries the one with the most free space, creating the JustPlay library there.

◇

Microsoft sign-in

Use a local display profile to set up folders and manage files. Starting Minecraft still requires a valid Minecraft Java account; JustPlay never collects passwords in its own form.

Simple by design

THREE SIMPLE STEPS

From download to the world.

Install JustPlay, set up your local player profile and choose a version. Connect a licensed game account when you are ready to play.

STEP 01 / SET UP

Choose a name

JustPlay creates its library on the writable drive with the most available storage and keeps your game files together.

STEP 02 / PROFILE

Set up your profile

Choose a local display name and organize your game library without signing in. Playing Minecraft still requires an account with Java Edition access.

STEP 03 / PLAY

Pick a build

Choose a release or snapshot, install its files and organize compatible mods and resource packs for your profile.

DOCUMENTATION

All the details. None of the guesswork.

Use the quick guide included with the desktop project for setup, versions, mods, resource packs and common launch errors.

Local profile & access

The local display profile is optional and only identifies your launcher setup. Launching Minecraft through JustPlay requires a legitimate Minecraft: Java Edition account; a launcher username is not an ownership check.

Versions & loaders

Vanilla versions use Mojang's manifest. Forge and Fabric installers use official project sources; OptiFine uses its official download page and may require manual steps.

Mods & resource packs

Use .jar files for Java mods and .zip files for Java resource packs. Keep files matched to the Minecraft version and loader.

Build the Windows installer

From the project folder on Windows, install Node.js LTS, run npm install, then npm run dist:win. The installer is created in the dist folder.
