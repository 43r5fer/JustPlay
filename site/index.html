BUILT AROUND YOUR NEXT GAME

Less hassle. More Roblox.

JustPlay focuses on the parts that should be simple—finding experiences, organizing favorites, and opening your game.

⌕

Search and discover

Look for Roblox experiences and browse popular picks in a single desktop interface. Game data and icons are requested from Roblox services.

↗

Play in one click

Press Play to pass the experience's place ID to the official Roblox client. If the app can't open, JustPlay falls back to the web game page.

♡

Favorites that stick

Keep a local collection of experiences on this PC and get back to your go-to games more quickly.

◩

Roblox profile connection

Optionally connect your Roblox profile through Roblox-hosted OAuth. Browse and launch games even before configuring sign-in.

⌑

No password collection

JustPlay never asks for Roblox credentials or session cookies. Profile tokens are stored encrypted when Windows secure storage is available.

⚙

Clean Windows app

A focused desktop window for discovery, favorites, account settings and help—without a browser full of extra tabs.

GOOD TO KNOW

Clear by design. Safe by default.

Roblox sign-in

Profile connection uses Roblox OAuth 2.0. The app owner must register a Client ID and configure the displayed localhost redirect URI. Game browsing and launch are available without OAuth.

Read Roblox OAuth documentation ↗

Game launching

JustPlay hands a place ID to the Roblox desktop app through the Roblox deep-link protocol. It doesn't bypass age gates, account restrictions, paid access, or Roblox's own game checks.

Read Roblox deep-link docs ↗

Build from source

Install Node.js, open the project folder and run npm install, then npm run dev. Use npm run dist:win to build a Windows installer.

Open source repository ↗

Independent project

JustPlay is an independent community launcher and is not affiliated with or endorsed by Roblox Corporation. The official Roblox app handles gameplay authentication.
