Saved-session play

Offers a short-lived, OS-encrypted previously authenticated session for already-installed profiles without inventing tokens or bypassing ownership checks.

Upgrading? v0.2.1 users can install v0.2.3 through the in-app updater. v0.1.1 users must install v0.2.0 once manually first.

01

Set up your folders

On first launch, choose a player display name and press Set up JustPlay. The app checks local drives for free space and creates a JustPlay folder on the drive with the most available space it can write to.

02

Choose the right account

Sign into your local JustPlay profile at startup or continue as a guest. To start official Minecraft Java Edition, use Microsoft sign-in with an account that has Java Edition access.

03

Install a version

Choose an official Release or Snapshot. Press Install & play. The first run downloads files from official sources; later launches use the installed profile. JustPlay auto-detects Java runtimes and picks a compatible major version.

04

Forge, Fabric & OptiFine

Forge and Fabric use their official installers. Select a Fabric build in the version library and press Install Fabric & play. OptiFine still uses its official website and separate installer flow; follow its instructions and select the result under Installed.

05

Add mods

Use a mod loader profile, then add JAR files in Mods. JustPlay copies each file to the shared staging folder and the selected profile's mods directory. Only install mods you trust and that match your loader and game version.

06

Add resource packs

Add Java resource packs as ZIP files. Open Minecraft and enable them under Options → Resource Packs. Bedrock-only .mcpack files and shader packs are not automatically installed by this initial build.

!
Troubleshooting

For Java errors, use Settings → Java Runtime → Auto-detect. For skin sync, sign in with Microsoft first. Saved-session play uses only a recent encrypted session from a previous successful Minecraft authentication and requires local game files to be complete. For sign-in errors, check your Microsoft account, game ownership and network. For Forge or Fabric problems, check the launch log and confirm your loader, Minecraft version, Java runtime, and mods are compatible.
